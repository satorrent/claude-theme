# Privacy policy

**Contrast Themes for claude.ai** (unofficial) · Last updated: 9 November 2026

**English** · [Español](#política-de-privacidad)

Contrast Themes does not collect, transmit, sell or share any data.

- **What it stores:** only the theme you choose, saved with Chrome's `storage` API on your own computer so it is applied the next time you open claude.ai.
- **What it reads:** nothing. It does not read your conversations, account details or anything else on claude.ai. It only adds a stylesheet to the page.
- **Network:** it makes no network requests and contains no analytics, tracking or third-party code.
- **Permissions:** `storage` to remember your theme, and access to `https://claude.ai/*` to apply it there. It runs on no other site.
- **Removing your data:** uninstalling the extension deletes everything it stored.

Questions: open an issue in this project's GitHub repository.

## Política de privacidad

Contrast Themes no recoge, transmite, vende ni comparte ningún dato.

- **Qué guarda:** solo el tema que eliges, guardado con la API `storage` de Chrome en tu propio ordenador para aplicarlo la próxima vez que abras claude.ai.
- **Qué lee:** nada. No lee tus conversaciones, los datos de tu cuenta ni nada más de claude.ai. Solo añade una hoja de estilos a la página.
- **Red:** no hace ninguna petición de red y no incluye analítica, seguimiento ni código de terceros.
- **Permisos:** `storage` para recordar tu tema y acceso a `https://claude.ai/*` para aplicarlo allí. No funciona en ninguna otra web.
- **Borrar tus datos:** al desinstalar la extensión se borra todo lo que guardó.

Dudas: abre una incidencia (issue) en el repositorio de GitHub del proyecto.
